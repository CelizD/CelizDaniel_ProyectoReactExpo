# Gymelyx

Gymelyx es una aplicación móvil enfocada en el entrenamiento, la alimentación y el seguimiento del progreso del usuario.

Este repositorio contiene la estructura inicial del proyecto desarrollada con React Native, Expo y TypeScript. La organización del código está pensada para mantener separadas las responsabilidades de la aplicación y facilitar su crecimiento durante el desarrollo.

## Tecnologías

- React Native
- Expo
- TypeScript
- Node.js
- npm
- Git
- GitHub
